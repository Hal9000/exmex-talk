# proj3

A deliberately uncompilable Elixir server for demonstrating Tidex compiler
diagnostics during server startup.

Build Tidex, run it in this directory, and press `s`. The server exits during
compilation and Tidex opens its compile-error modal automatically. Press `e`
to open the source or `o` to view complete server output. After closing the
error modal, `v` also opens that raw server output.

This project is intentionally broken and requires no setup or reset.

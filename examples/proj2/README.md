# proj2

A deliberately uncompilable Elixir project for demonstrating Tidex compiler
diagnostics from a test command.

Build Tidex, run it in this directory, and press `t`. The test command stops
during compilation. Press `f` to inspect the compile error, `e` to open its
source, or `o` to view the complete command output.

This project is intentionally broken and requires no setup or reset.
